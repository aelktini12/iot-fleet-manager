# Documentation d'architecture — IoT Fleet Manager

Ce dossier contient la documentation d'architecture du projet, versionnée avec le code.

## Contenu

- **[`architecture.md`](./architecture.md)** — Le dossier d'architecture complet, structuré selon le canevas **arc42** (12 sections), avec diagrammes **C4** (Mermaid). Couvre l'existant et la cible IoT.
- **[`adr/`](./adr/)** — Les **Architecture Decision Records** : une fiche par décision structurante (contexte, décision, conséquences, statut). Voir [l'index](./adr/README.md).

## Comment lire

1. Commencer par `architecture.md` §1 à §3 pour le **quoi** et le **pourquoi**.
2. Parcourir les **ADR** pour le détail des choix (et de ceux encore *Proposed*).
3. La **roadmap** est en §9 de `architecture.md` ; le **suivi d'avancement** opérationnel vit sur Notion.

## Conventions

- Les diagrammes sont en **Mermaid** — rendus nativement sur GitHub.
- Les éléments *(cible)* / en pointillés dans les diagrammes ne sont **pas encore implémentés**.
- Ce document est **vivant** : il est enrichi à chaque phase.
